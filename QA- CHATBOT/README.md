# Industrial RAG Chatbot

## Overview

A Retrieval-Augmented Generation (RAG) chatbot built using:

* LangChain
* FAISS
* BM25
* Cross-Encoder Reranking
* Groq LLMs

## Features

* Hybrid Retrieval (FAISS + BM25)
* Query Rewriting
* Cross-Encoder Reranking
* Multi-document Search
* Source Citations
* Evaluation Framework

## Run

```bash
python app.py
```

## Evaluation

```bash
python answer_evaluation.py
```
